# CLAUDE.md

`AGENTS.md` is the canonical contributor guide for this repository and applies
to agents and humans alike. **Read it first.** This file exists only so it is
not missed by a tool that looks for this filename, and it deliberately
duplicates nothing.

`AGENTS.md` carries the cold-start reading order and the working discipline:
isolated worktrees, one PR per coherent unit, the commit message carries the
why, never push to `master` from a shared build.
